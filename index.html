Gmail Schedule Assistant

個人開発 · メールから予定の確認・登録までを支援

研究室から届く多くのメールの中で、重要な予定の確認とカレンダーへの転記に手間がかかるという課題から開発しました。Google Apps Script と Gemini API を組み合わせ、メール本文に埋もれた日程情報を整理し、Google Chat で確認できるようにしました。

  • 日程情報の構造化：イベント名、開始・終了日時、場所、会議情報、予約リンクを抽出。1通に含まれる複数の開催日程や、「いずれか1回参加」「全日程参加」といった参加条件も解析します。
  • 確認から行動までを支援：Google Chat に日程ごとのカードを通知。予約ページへの移動や、内容を確認して Google カレンダーに追加する操作につなげます。
  • メール処理の分離：メインメール側で対象メールをラベル管理し、専用 Bot アカウントに転送。Bot 側で解析・通知・処理後のアーカイブを行う構成にしました。
  • 継続運用を意識した設計：過去日程の除外、処理ロックと転送済みラベルによる重複処理の抑制、API 混雑時の指数バックオフ、解析失敗時の通知・ラベル付けを実装しました。

技術：JavaScript / Google Apps Script / Gemini API / Gmail / Google Chat Webhook / Google Calendar 登録リンク

私は新しい技術や知識を学ぶことが好きで、 興味を持った分野には主体的に取り組みます。 また、周囲との協力を大切にしながら、 課題解決に向けて着実に行動することを心掛けています。


現在は法政大学大学院で、 機械学習におけるハイパーパラメータ最適化の研究に取り組んでいます。 特に、PED-ANOVAを用いたハイパーパラメータの重要度分析に着目し、 モデルの性能に影響するパラメータを理解することで、 より効率的な探索につなげることを目指しています。 研究を通じて、データ分析能力や論理的思考力だけでなく、 仮説立案から検証・改善までを繰り返す問題解決力を身につけてきました。


また、身近な課題を見つけ、生成AIを活用した仕組みとして形にすることにも取り組んでいます。 個人開発の「Gmail Schedule Assistant」では、メールからの日程抽出だけでなく、 通知を受けて予約やカレンダー登録に進むまでの流れを設計しました。 APIエラー時の再試行や重複処理の抑制も実装し、継続して使う場面を意識した開発を心掛けています。


今後はAIや機械学習に関する実践的な開発経験を積みながら、 社会に価値を提供できるサービスやプロダクトの開発に携わりたいと考えています。
